## STEP 3: UPDATE THE JSON-LD SCHEMA MARKUP

This is the most important change for search engines. The schema markup is in the `<head>` section — likely in a layout file, a metadata component, or injected via Next.js Head/metadata.

**Find the `openingHoursSpecification` block in the schema.** It currently looks something like this:

```json
"openingHoursSpecification": [
  {
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday"],
    "opens": "07:30",
    "closes": "17:00"
  }
]
```

**Replace it with this (adds Saturday, updates all times):**

```json
"openingHoursSpecification": [
  {
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday"],
    "opens": "07:00",
    "closes": "19:00"
  },
  {
    "@type": "OpeningHoursSpecification",
    "dayOfWeek": ["Saturday"],
    "opens": "07:00",
    "closes": "13:00"
  }
]
```

**IMPORTANT:** The schema may appear in multiple places:
- Homepage schema (the main HVACBusiness entity with `@id`)
- Friendswood area page schema (`/areas/friendswood`)
- Alvin area page schema (`/areas/alvin`)
- Possibly other area/service pages

**Search the entire codebase** for `07:30` and `17:00` to find ALL instances of the old hours in schema markup. Every single one must be updated. Use a project-wide search (grep or find-in-files) to make sure nothing is missed.
